# Sokol_CleanTV для Android 0.1.1

Готовый установочный APK для Android 8.0 и новее.

[Скачать APK](https://github.com/sokolovroman163-creator/Sokol_CleanTV-Android-0.1.1.apk/raw/refs/heads/main/Sokol_CleanTV-Android-0.1.1.apk)

Откройте ссылку на телефоне, скачайте файл и разрешите установку из используемого браузера или файлового менеджера. Также можно скачать весь репозиторий через Code → Download ZIP и извлечь APK.

Приложение подключается к Android TV / Google TV в одной локальной сети. Включены выбор приложений для отключения с защитой Google Play и системных компонентов, обои с телефона, необязательная установка ByeByeDPI, резервные копии настроек и восстановление. Копия не является образом прошивки или копией личных данных.

Первая тестовая версия: прошли 32 теста логики, Android Lint и установка обновления поверх 0.1.0 на эмуляторе. Полный сценарий на физических Poco и телевизорах ещё требует проверки.

[Инструкция, ограничения и исходники](https://github.com/sokolovroman163-creator/Sokol_CleanTV/tree/android-app/android-app)

Контрольная сумма установочного файла находится в SHA256SUMS.txt.

## Исправления 0.1.1

Исправлена ошибка «Новый главный экран не стал основным». Сначала проверяется запуск нового экрана, затем отключается штатный, назначается новый и проверяется Home. Добавлена защита системных служб Xiaomi/Amlogic и проверка точного возврата при сбое.

Установите APK поверх прежней версии, не удаляя приложение. Подключитесь к ТВ заново. Для первой проверки выберите только «Новый главный экран». После проверки можно отдельно выполнить очистку и установить ByeByeDPI.
