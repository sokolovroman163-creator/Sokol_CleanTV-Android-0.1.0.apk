# Sokol_CleanTV для Android 0.1.0

Готовый установочный APK для Android 8.0 и новее.

[Скачать APK](https://github.com/sokolovroman163-creator/Sokol_CleanTV-Android-0.1.0.apk/raw/refs/heads/main/Sokol_CleanTV-Android-0.1.0.apk)

Откройте ссылку на телефоне, скачайте файл и разрешите установку из используемого браузера или файлового менеджера. Также можно скачать весь репозиторий через Code → Download ZIP и извлечь APK.

Приложение подключается к Android TV / Google TV в одной локальной сети. Включены выбор приложений для отключения с защитой Google Play и системных компонентов, обои с телефона, необязательная установка ByeByeDPI, резервные копии настроек и восстановление. Копия не является образом прошивки или копией личных данных.

Первая тестовая версия: прошли 21 тест логики и две инструментальные проверки на эмуляторе. Полный сценарий на физических Poco и телевизорах ещё требует проверки.

[Инструкция, ограничения и исходники](https://github.com/sokolovroman163-creator/Sokol_CleanTV/tree/android-app/android-app)

Контрольная сумма установочного файла находится в SHA256SUMS.txt.
